# 构成主义海报生成器（v0.2）

换上你的角色、打上标题，就是一张构成主义海报：人物会被**剪成纸 / 红 / 黑三色大块纸片**（直边、平涂、没有渐变；头发、脸、衣服各剪成一大块，块和块之间留一条细黑线，脸是一整块纸、不留五官），口号塞进从嘴里喊出去的大喇叭，字的上下沿顺着喇叭的两条边做透视。
配套视频：《（发布时填标题）》—— B 站链接发布时填。在线版（打开就用）：https://azusagawakaedesama.github.io/constructivism-poster/

## 怎么用
1. 整个文件夹一起下载（ZIP 解压），双击 `index.html` 就能用，不用装任何东西。少了 `fonts/`，标题会变成系统的细体字。
2. 点「换成你的角色」上传图（**透明背景的 PNG 最好**）；也可以直接把图拖进来，或者 Ctrl+V 粘贴截图。图只在你的电脑里处理，不会上传。
3. 改标题、口号，点「下载 PNG」。人物的剪纸版可以「下载人物 SVG」：Illustrator 能直接打开，进 AE 先在 Illustrator 里另存为 .ai。

几个小技巧：
- 喇叭尖没对准嘴：在画面上点一下她的嘴。
- 人物自己拿着喇叭：用 URL 参数让喇叭锥接在她的喇叭口上，锥的两条边就是她喇叭两条边的延长线（见下文 `horn`）。
- 想要旧版那样的线稿（眼睛、嘴、刘海的细线）：勾「留线稿」。默认不留，脸是一整块纸。不要头发、脸、衣服之间那几条分块线：URL 加 `pieces=0`。
- 想让别的颜色变红：「红色给谁」切到「点选」，直接点人物身上那块颜色（同一种颜色的地方会一起变）。
- 带背景的图：纯色底（白底、蓝底）会自动去掉；复杂背景得先抠图，不然剪纸会连背景一起剪，这时页面先用「去色照片」。
- 键盘：`0`–`4` 切步骤，`a` 画出主斜轴，`g` 去色看三档，`r` 在去色照片 / 形状重绘之间切换。

想用 URL 参数批量出图（`img=` 读文件夹里的图）或者交给 AI agent：在 `index.html` 所在的文件夹里打开终端，运行 `python -m http.server 8000`（mac 用 `python3`），再打开 http://localhost:8000 。参数见下文，agent 的用法和量化门槛见 `SKILL.md`。

## 视频里那几招
| 招 | 怎么做 | 代码里在哪 |
|---|---|---|
| 先找一根斜线 | 标题、色条顺着同一根主斜轴排，其余元素横平竖直 | `drawA` 里所有 `rotate(rad(a))` 共用一个角度 `a` |
| 只留三个颜色 | 纸（亮）/ 红（中间）/ 黑（暗），不要渐变和投影 | `PALETTES` |
| 人也剪成形状 | 暗的剪成黑，亮的留成纸，最想让人看的那块染红；头发、脸、衣服各剪成一大块（块和块之间一条细黑线，五官不要）；弧线全改成直边 | `redraw.js` |
| 形状得有台词 | 圆框住脸＝看这里；喇叭从嘴里喊出去＝她在喊；她自己拿着喇叭时，锥接在她的喇叭口上、两条边顺着她喇叭的两条边 | `drawA` 第 3 步、`coneGeometry`、`drawCone` |
| 字也是形状 | 标题顶出画面、压在色带上，口号在喇叭里越喊越大、上下沿和喇叭两边平行，小字落在斜线的刻度上 | `drawA` 第 4 步、`drawSlogan` |

左栏下方实时显示**实测面积**（纸 / 红 / 黑各占多少）和去色后暗 / 中 / 亮的比例，方便对照风格卡里的目标（A：纸 40–60%、红 15–25%、黑 20–25%）。
深色衣服的角色默认基本落在区间里（3:4 实测 纸 / 红 / 黑：要乐奈 60 / 18 / 22，千石由乃 53 / 22 / 24，三角初华 56 / 15 / 28，黑裙的初华黑多 3 个点）。浅色角色剪出来大多是纸（白头发、白衣服、脸都是纸），靠分块线分出头发、脸和衣服；想要更多黑块就换深色衣服的图，或者先做一张纸 / 红 / 黑的平涂稿再丢进来。

## 三种风格
- **A 原典宣言**：1920 年代俄国构成主义，红黑纸三色，人物喊话，口号装进喇叭（致敬罗德琴科 1924 年《书籍》海报）。
- **B 至上主义**：马列维奇式的白底漂浮几何，人物只剩剪影（形状重绘时是拉直后的外形）。
- **G 工业构成**：混凝土灰、巨字压边、警示胶带斜穿，接近《明日方舟》乌萨斯 / 「人们，我们」的用法；人物用浅灰 / 警示黄 / 黑三色。

## URL 参数
`?preset=A&step=4&title=来浮泽&slogan=全员集合&sub=FREEDOM%20ZONE&info=2026.10&angle=-16&size=1080x1440&img=你的图.png&render=1`

- 人物：`mirror=1` 左右翻转人物（人物朝左时用：喇叭锥总是往右喊，翻过来喇叭和喊话才同向，界面上是「人物镜像」勾选框）；`fig=photo` 用去色照片（默认 `redraw` 形状重绘）；`eps=5` 直边程度（2–10，默认 5，旧版 4；越大折角越硬、块越整）；`lines=1` 留线稿（眼睛、嘴、刘海的细线都画上；默认不留，界面上是「留线稿」勾选框）；`merge=0.4` 三色图里小于人物面积多少（百分数）的碎块并进四周（默认 0.4，`0` 不并）；`pieces=0.6` 纸色分块：小于人物面积多少（百分数）的格子并掉，剩下的大块之间画分块线（默认 0.6，`0` 不分块、不画分块线）；`red=auto`（默认）/ `red=none` 不要红 / `red=0,3` 只让这几个色块红（色块号见页面 `body.dataset.redraw`）。
- 旧版的分法：`lines=1&eps=4&merge=0&pieces=0`（画线稿、容差 4、不并碎块、不分块）。补缝的画法（红块、黑块的同色细边、贴着外轮廓的折点挪到外形边上）是新的，所以和旧版截图不是逐像素相同。
- 脸和嘴：默认自动找；`mx=0.33&my=0.16` 指定嘴（喇叭尖），`fx=0.3&fy=0.12` 指定脸（红圆圆心）。都是相对「裁掉透明边后的人物图」的位置（0–1）。
- 看重绘过程：`view=three`（原图 → 三色 → 剪纸，给视频用）/ `steps`（原图 + ①–④）/ `k` / `3c` / `line`（③：不留线稿时是分块，留线稿时是线稿）/ `shape`；多格并排时默认 16:9。
- 检查层：`axis=1` 画出主斜轴、`gray=1` 去色看三档。只画在预览上，下载的 PNG 不带。
- `workers=0|1` 关 / 开多线程（`render=1` 时默认关，方便无头截图）。
- 旋钮（只有 A 用，调面积比时最有用）：`wedge` 喇叭锥半角，单位度，默认 12；`circle` 红圆半径倍数，默认 1.2；`bar` 红条粗细倍数，默认 1.6；`band` 黑带高度占画面高，默认 0.075，设 0 关掉。
- 人物自己拿着喇叭（只有 A 用）：`horn` = 锥从离尖端多远的地方才开始画（按人物高算，默认 0 = 从嘴开始、压在人物上面，同旧版）。量法：在**镜像、裁掉透明边以后**的人物图上，取她喇叭外轮廓的上下两条外边（喇叭外轮廓凸包上下两条长边：直锥就是锥的两条边，喇叭口是一圈椭圆时两条边和喇叭口相切），`mx` / `my` = 两条边延长线的交点，`angle` = 两条边的角平分线方向（度，y 向下，朝右上为负；标题和黑带跟着同一根轴），`wedge` = 两条边夹角的一半，`horn` = 从交点沿角平分线量到两条边碰到喇叭口那两点的距离（取近的那个）÷ 人物高，`fx` / `fy` 给脸（红圆圆心）。这样锥画在人物后面，从她的喇叭口里伸出来，两条边就是她喇叭两条边的延长线；形状重绘时剪纸人物的外形拉直过，喇叭边和量出来的线会差 1–3px，所以锥的两条边各自平移到「人物外形在喇叭口那一处」（最多挪人物高的 0.6%，角度不动），接缝处两条黑边对齐、没有台阶。口号从她的喇叭外面开始，喇叭外面地方不够时，锥身伸长到锥边出画面为止（喇叭口可以出血），但锥和喇叭口都不伸进标题区（标题下面那条纸色带的上沿，再留短边 1.5%），不然喇叭口的角会被纸色带切掉。
- `horn=0`（默认）时锥的尖端、角度、半张角、画的顺序和旧版一样，但口号改成了按字分格透视（见下文），锥长和字号都跟着变（和旧版比）：3:4 下锥长 +4%–10%，第一个字的墨迹高 −3%–+5%；16:9 下锥长 −11% / −11%，第一个字 −16% / −17%（两张测试立绘 45.5 → 38.0px、47.0 → 39.0px，仍高于短边 2.2% 的门槛 23.8px）；最后一个字都更大（+14% 到 +42%）。锥和喇叭口同样不伸进标题区（这几种默认画幅下碰不到，长度没变）。

## 原理（给想改代码的人）
形状重绘全在浏览器里算，代码都在 `redraw.js`，不依赖任何库，Node 里也能 `require`。

| 步 | 白话 | 做法和关键数 |
|---|---|---|
| ① 色块 | 先把布纹、高光抹平，再把颜色归成 9 堆 | 人物裁掉透明边、缩到 1400 高（特别宽的图限制在 260 万像素以内）；mean-shift 平滑（半径 7px、颜色半径 22）；Lab 颜色空间 k-means，K = 9 |
| ② 三色 | 每堆颜色决定当纸、红还是黑 | 本来就是红 / 橙 / 粉且够鲜 → 红；暗（明度 < 40）→ 黑；其余 → 纸。人物里黑太少（< 8%）就把最暗的那堆纸补成黑，红太少（< 5%）就把「彩度 × 面积」最大的中间调补成红。9×9 众数滤波两遍；红碎块 < 0.4%、黑碎块 < 0.06% 并入纸 |
| ③ 分块 | 小碎块并进大块；纸色的地方再分成头发、脸、帽子、袖子这些大块，块和块之间留一条细黑线（五官不留） | 三色图里每种颜色的连通块 < 人物面积 0.4% 的，改成它四周最多的那种颜色（从小到大逐块改，最多 4 轮）。纸色分块：平滑图里相邻、颜色差 < 5（Lab，明度差按 1/1.5 算）的纸色像素连成一格，原画线稿（黑帽 > 38）上的像素不连；两格的边界压在线稿上的比例 < 35% 就并成一格（阴影、高光、腮红没有线稿，都并掉）；再把 < 人物面积 0.6% 的格子并进接触最多的邻格（眼睛、嘴、发丝、毛边）。剩下的大块之间的边界就是分块线，和外轮廓露出来的那一半一样粗（3.5px）；一头悬空、短于人物高 2% 的不画。线稿默认不画进剪纸（`lines=1` / 勾「留线稿」才画：黑帽变换 > 38，全身留 ≥ 160px 的长线，脸附近连 ≥ 18px 的短线也留） |
| ④ 直边 | 把每块的边剪成折线 | 描出每一层的轮廓（含洞），Douglas–Peucker 拉直（直边程度默认 5，外形 ×0.8，线稿 1.1），偶奇规则填色；贴着外轮廓的红块、黑块，离外形边 ≤ 5px 的折点挪到外形边上；画法：人物外轮廓先描 7px 黑边（直角接头）→ 填纸 → 分块线（只画在外形里面）→ 红块、黑块各描一圈同色 5px 细边再填色（补上拉直以后剩下的纸色细缝）→ 外轮廓只在外形外面再描一遍（盖住伸出外形的细边） |

拖「直边程度」只重算第 ④ 步的拉直；改红色重算 ②、③（并碎块、分块）和 ④；点嘴只重算线稿（留线稿时才算）；改字、角度、画幅都不重算。「看重绘过程」里的 ③ 不留线稿时显示分块（并完碎块的三色图 + 大块之间的边界），留线稿时显示线稿。
口号的透视：整句先排成一行（离屏），按字切成几格，每格用一个单应变换贴进锥里的一段梯形——梯形上下沿是锥的两条边各往里收一个固定边距，所以字的上下沿和锥边平行；每格多长按这个字原来的宽高比定，字不压扁，一格比一格大。整句只用一个单应变换的话，长度对上以后第一个字会被压窄、最后一个字被拉宽（两个字、16° 的锥约 0.8 / 1.5 倍，四个字、12° 的锥约 0.6 / 2.9 倍），所以按字分格。第一个字的高不小于画面短边的 2.2%。放不下时：从嘴开始的锥，口号整体往嘴边挪；接在人物喇叭上的锥，先把字横向压到 0.8 换贴边，字和锥边之间还空太多就让锥伸长（喇叭口可以出血，标题区那一侧不出血）；第一个字还小于 2.2% 时继续压窄（最低 0.35）。排版用 240px 的一行量每个字的宽高比；真正贴进锥里时按最后一个字的实际高度（多留 25%）另排一行再缩小贴进去，字边不发虚。
喇叭尖找嘴的办法：头部那一段里找肤色连成的一块，块里被皮肤整圈围住的那个小洞就是嘴（眼睛一般连着刘海，不成洞）；找不到就按头部位置估，点一下就能改。

速度（作者的电脑 i5-12600K，1800×2160 立绘 3 张，从开算到出图）：6 线程 0.6–0.8 秒；单线程（`render=1`）0.9–1.2 秒；把 CPU 限速 3 倍、只给 3 个线程模拟普通笔记本，1.4–1.9 秒（限速 4 倍 1.8–2.6 秒）。其中分块 0.06–0.08 秒（限速 4 倍 0.19–0.26 秒），并碎块 0.05–0.1 秒（限速 4 倍 0.2–0.33 秒）。

和 Python 参考实现的关系：步骤和参数照一份 Python + OpenCV 的参考实现移植（参考实现不在这个仓库里）。第 ② 步的三色图（「看重绘过程」里的「② 三色」）：同一份像素喂给两边，逐像素一致率 99.2%–99.9%（8 张测试立绘）；在浏览器里从原图一路算下来，因为缩图算法不同，是 98%–99.7%（3 张测试立绘）。这一步的判定规则没改过：3 张测试立绘和示例图的三色面积（两位小数）和改之前一样。三色图之后，剪纸成品和参考实现不再逐像素对应：这里多了「小碎块并进大块」和「分块线」，默认不画线稿、直边程度 5（参考实现画线稿、容差 4），所以块更大、脸上没有五官，头发、脸、衣服之间用分块线分开。其他不一样的地方：k-means 在颜色直方图上做，随机数和 OpenCV 不同，卡在门槛边上的色块偶尔会分到别的角色；多了「黑太少补黑」这一条；轮廓沿像素边描，线稿的折点比 OpenCV 多一些。
