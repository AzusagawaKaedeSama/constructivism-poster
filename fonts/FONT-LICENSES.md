# 字体授权

这个文件夹里的两款字体都不是 MIT，各自按自己的许可随仓库分发，许可全文就在本文件夹里。

| 文件 | 字体与版本 | 版权行 | 许可（全文） |
|---|---|---|---|
| `NotoSansSC-Black-gb2312.otf` | Noto Sans S Chinese Black，1.000 版（2014），按 GB2312 字符集子集化 | Copyright © 2014 Adobe Systems Incorporated. All Rights Reserved. | Apache License 2.0：`LICENSE-Apache-2.0.txt` |
| `BarlowCondensed-SemiBold.ttf` | Barlow Condensed SemiBold，1.408 版（Jeremy Tribby / Tribby Type） | Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow) | SIL Open Font License 1.1：`OFL.txt` |

- **Noto 的版本**：这里用的是 2014 年发布的 1.000 版，当时 Noto Sans CJK 按 Apache-2.0 发布。现在 https://github.com/notofonts/noto-cjk 上的新版本改成了 OFL 1.1，两者许可不同，以本表为准。
- **子集化**：`NotoSansSC-Black-gb2312.otf` 只删掉了 GB2312 以外的字形（繁体字、日文假名、♪ ★ ～ 等都不在里面，页面会换成系统黑体），其余字形没有改动。按 Apache-2.0 第 4 条，这里注明：此文件是原字体的修改版（删字）。
- **Barlow** 没有保留字体名（Reserved Font Name），文件未修改。
